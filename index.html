      10 / AI AGENT INTEGRATION

      Model Context Protocol (MCP) Server

      Give Claude, Antigravity, and Cursor direct API access to your brand book, design tokens, and copy guidelines so every AI-generated asset is 100% on-brand.

      1

      Start the Brand Hub MCP Server

      Run the zero-dependency Node.js server locally over stdio or connect directly to your IDE.

      2

      Connect to Claude / Antigravity / Cursor

      Add the snippet to your claude_desktop_config.json or Antigravity mcpSettings.json.

      3

      Query Brand Rules in Real Time

      Ask: "Check if this headline matches Indian Garage voice" or "Export current color tokens for CSS".

      claude_desktop_config.json

  "mcpServers": {
    "indian-garage-hub": {
      "command": "node",
      "args": [
